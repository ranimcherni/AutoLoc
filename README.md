\# AutoLoc — Plateforme de gestion de location de véhicules



\## Objectifs du projet

Application Java / Spring Boot pour la gestion multi-agences de location de véhicules.



\## Acteurs identifiés

\- \*\*Client\*\* : consulte les véhicules disponibles, réserve, paie

\- \*\*Agent d'agence\*\* : gère les réservations de son agence

\- \*\*Responsable d'agence\*\* : supervise l'activité de son agence

\- \*\*Administrateur\*\* : gère l'ensemble du système



\## Stack technique

\- Java 17

\- Spring Boot, Spring Data JPA, Spring MVC

\- MySQL 8 (base `autoloc\_db`)

\- Maven

\- Lombok

\- JUnit 5, Mockito

\- Git + GitHub
